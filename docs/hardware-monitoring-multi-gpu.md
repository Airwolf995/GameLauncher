# Hardware-Monitoring mit zwei Grafikadaptern prüfen

1. Aktiviere die integrierte Grafikeinheit manuell im BIOS und starte Windows neu. Der Monitor kann an der RTX 4080 SUPER angeschlossen bleiben. Kontrolliere mit `pnputil /enum-devices /class Display /connected` und unter **Task-Manager → Leistung**, ob Windows sowohl die AMD-Grafikeinheit als auch die RTX erkennt. DXGI kann auch Adapter ohne angeschlossenen Bildschirm auflisten.
2. Starte den Launcher neu und öffne das Overlay. Vergleiche es mit der Seite der **RTX 4080 SUPER** im Task-Manager. Im Launcher-Log steht die ausgewählte Karte mit ihrer Windows-LUID. Die RTX sollte wegen ihres größeren dedizierten Videospeichers ausgewählt sein. Der Windows-Wert für die Speicherkapazität kann durch Treiberreservierungen vom NVIDIA-Wert abweichen.
3. Starte ein Spiel auf der RTX, während das Overlay bereits sichtbar ist. Vergleiche die Auslastung und die Belegung des dedizierten Speichers über mehrere Aktualisierungen. Im Task-Manager unter **Details** hilft die Spalte **GPU-Engine**, um die tatsächlich verwendete GPU des Spiels zu prüfen. Einzelwerte können wegen unterschiedlicher Abtastzeitpunkte schwanken.
4. Weise für die Gegenprobe eine zweite Testanwendung unter **Einstellungen → System → Anzeige → Grafik** der AMD-iGPU zu und starte sie neu. Das geht auch ohne Monitor an der iGPU, sofern Windows und die Anwendung sie zur Auswahl anbieten. Prüfe die GPU-Engine im Task-Manager. Das Overlay zeigt weiterhin die RTX und zählt die AMD-Last und ihren Speicher nicht hinzu. Stelle die Grafikeinstellung der Testanwendung danach wieder zurück.
5. Blende das Overlay für mindestens zehn Sekunden aus und öffne es erneut. Vergleiche die Werte erneut nach zwei Aktualisierungen. Prüfe bei laufendem LibreHardwareMonitor die **GPU Core**-Temperatur. Für die RTX liefert auch `nvidia-smi --query-gpu=name,pci.bus_id,temperature.gpu,utilization.gpu,memory.used,memory.total --format=csv` Referenzwerte. NVIDIA und Windows messen Last und Speicher nach unterschiedlichen Regeln.
